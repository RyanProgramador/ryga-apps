Política de Privacidade

Última atualização: novembro de 2026.

Esta política descreve como a Ryga Apps trata informações nos aplicativos que publica. Cada aplicativo pode ter uma política própria com detalhes adicionais, informada na página do app na loja.

Dados coletados

Coletamos apenas os dados necessários para o funcionamento de cada aplicativo, como informações de cadastro fornecidas pelo próprio usuário e dados técnicos básicos para diagnóstico de erros.

Uso dos dados

Os dados são usados somente para fornecer, manter e melhorar os aplicativos. Não vendemos dados pessoais a terceiros.

Compartilhamento

Dados podem ser processados por serviços de terceiros necessários ao funcionamento do app (por exemplo, hospedagem e análise de falhas), sempre de acordo com a LGPD.
